
# GitHub Access Audit Script

This script was used as part of my hands-on learning from [Abhishek Veermaalla's DevOps Zero to Hero](https://www.youtube.com/playlist?list=PLdpzxOOAlwvIKMhk8WhzN1pYoJ1YU8Csa) series.

It demonstrates how to:

- Use GitHub APIs via shell scripts.
- Retrieve repository collaborator access info.
- List users who have permission to a given repository.
- Execute scripts within an AWS EC2 environment.

## ⚙️ What I Learned

- How GitHub repository access can be queried via terminal.
- Real-time script execution from an EC2 instance.
- Basics of using GitHub personal access tokens and API headers securely.
